## Quick glance

- A **CFG** G = (V, Σ, P, S) has productions A → α with a single nonterminal on the left. A **CFL** is a language generated by a CFG; equivalently accepted by a **nondeterministic PDA** (NPDA).
- PDA = finite automaton + one stack. It can count and match **one** unbounded quantity (a^n b^n, palindromes) but cannot compare two (a^n b^n c^n, ww).
- Acceptance by **final state** and by **empty stack** are equivalent in power for NPDA. For DPDA, final-state acceptance is strictly stronger (DPDA with empty-stack acceptance only accepts prefix-free DCFLs).
- **NPDA > DPDA:** DCFL ⊊ CFL. {ww^R} is a CFL but not a DCFL; {w c w^R} is a DCFL.
- **Ambiguous** grammar: some string has two parse trees (equivalently two leftmost derivations). Ambiguity is a property of the grammar; an *inherently ambiguous* language has no unambiguous grammar (example {a^i b^j c^k : i = j or j = k}). Ambiguity is undecidable.
- **CNF:** every rule A → BC or A → a, so a string of length n has a derivation of exactly **2n − 1** steps. **GNF:** every rule A → aα, so derivation takes exactly **n** steps.
- CFLs are closed under union, concatenation, star, reversal, homomorphism, intersection **with a regular language**; **not** under intersection or complement. DCFLs are closed under complement and regular intersection, but not union/intersection/concatenation/star/reversal.
- CYK decides membership in O(n³) for a CNF grammar. Emptiness, finiteness, membership are decidable; equivalence, ambiguity, universality, disjointness are **undecidable**.
- #1 trap: intersection of two CFLs is not necessarily a CFL (a^n b^n c^m ∩ a^m b^n c^n = a^n b^n c^n), and therefore CFLs are not closed under complement.

## 1. Context-free grammars

**Intuition.** A grammar is a set of rewriting rules that generates strings. "Context-free" means the left side is a single nonterminal, so a nonterminal can be rewritten wherever it appears, regardless of its neighbours. This is the right model for nested structure: balanced brackets, arithmetic expressions, program blocks.

**Definition.** G = (V, Σ, P, S): V nonterminals (variables), Σ terminals, P productions A → α with A ∈ V and α ∈ (V ∪ Σ)*, start symbol S. L(G) = {w ∈ Σ* : S ⇒* w}.

**Derivation** is a sequence of rewriting steps. **Leftmost** derivation always rewrites the leftmost nonterminal; **rightmost** the rightmost. A **parse (derivation) tree** has the start symbol as root, a production's right side as the children of a node, and the string (the **yield**) read from the leaves left to right.

### 1.1 Grammars for classic languages

| Language | Grammar |
| --- | --- |
| a^n b^n, n ≥ 0 | S → aSb \| ε |
| a^n b^n, n ≥ 1 | S → aSb \| ab |
| a^n b^m, n ≠ m | S → aSb \| A \| B; A → aA \| a; B → bB \| b |
| Palindromes over {a,b} | S → aSa \| bSb \| a \| b \| ε |
| ww^R | S → aSa \| bSb \| ε |
| Equal number of a's and b's | S → aSbS \| bSaS \| ε |
| Balanced parentheses | S → (S)S \| ε |
| a^i b^j c^k with i = j | S → AC; A → aAb \| ε; C → cC \| ε |
| a^i b^j c^k with j = k | S → AB; A → aA \| ε; B → bBc \| ε |
| {a^i b^j c^k : i = j or j = k} | S → S1 \| S2; S1 → AC; S2 → A'B (rules above) |

**Worked example: length-and-count bookkeeping.** For S → aSb | ab, derive aaabbb: S ⇒ aSb ⇒ aaSbb ⇒ aaabbb (3 steps, the last uses S → ab). Language = {a^n b^n : n ≥ 1}. **Worked example 2:** S → aSbS | bSaS | ε generates "abba"? S ⇒ aSbS ⇒ abS (first S → ε) ⇒ ab·bSaS ⇒ abba (both remaining S → ε). abba has 2 a's and 2 b's, as required.

### 1.2 Ambiguity

A grammar is **ambiguous** if some string has two or more distinct parse trees (equivalently two distinct leftmost derivations, or two distinct rightmost derivations).

**Worked example.** E → E + E | E * E | id. The string id + id * id has two parse trees:

```text
   E                      E
 / | \                  / | \
E  +  E                E  *  E
|    / | \           / | \   |
id  E  *  E          E  +  E  id
    |     |          |     |
    id    id         id    id
 (id + (id*id))       ((id+id) * id)
```

Leftmost derivation 1: E ⇒ E+E ⇒ id+E ⇒ id+E*E ⇒ id+id*E ⇒ id+id*id.
Leftmost derivation 2: E ⇒ E*E ⇒ E+E*E ⇒ id+E*E ⇒ id+id*E ⇒ id+id*id.
Two different leftmost derivations, so ambiguous. **Fix** by encoding precedence and associativity in layers: E → E + T | T; T → T * F | F; F → id | (E). This is unambiguous, generates the same language, and makes `*` bind tighter and both operators left-associative. Other classic ambiguous grammars: the dangling-else, S → SS | a | ε (ε-loops), S → aS | Sa | a.

**Facts.**

- Ambiguity belongs to a grammar, not (usually) to a language. Many ambiguous grammars have an equivalent unambiguous one.
- An **inherently ambiguous** CFL has *every* grammar ambiguous. Standard example: **{a^i b^j c^k : i = j or j = k}**. The strings a^n b^n c^n satisfy both conditions and must have two derivations (one through each condition).
- Deciding whether a CFG is ambiguous is **undecidable**. Every regular language has an unambiguous grammar. Every DCFL has an unambiguous grammar (so DCFLs are never inherently ambiguous).
- Counting parse trees: for S → SS | a, the number of parse trees of a^n is the Catalan number C(n−1): a^3 has 2, a^4 has 5.

## 2. Grammar simplification, CNF, GNF

Order matters: **ε-removal, then unit-removal, then useless-symbol removal** (useless last, because the earlier steps can create useless symbols).

### 2.1 Eliminating ε-productions

A variable is **nullable** if A ⇒* ε. Compute by closure: A is nullable if A → ε, or A → X1…Xk with every Xi nullable. For each production, add every version with any subset of nullable symbols deleted; then drop all A → ε. (If ε ∈ L the start symbol keeps S → ε, with a new start symbol if S appears on a right side.)

**Worked example.** S → AB; A → aA | ε; B → bB | ε. Nullable = {A, B, S}. Replace each production by its subset versions:

- S → AB | A | B | ε (delete A, B, both)
- A → aA | a
- B → bB | b

Language is a*b*, unchanged (verified by enumerating all strings up to length 6). Keep S → ε because ε ∈ L.

### 2.2 Eliminating unit productions

A **unit production** is A → B with B a variable. Compute for each A the set of variables reachable by unit rules (the *unit closure*), then replace: for each B in closure(A) and each non-unit production B → α, add A → α.

Continuing: S → AB | A | B | ε. closure(S) = {S, A, B}. Replace S → A with S → aA | a, and S → B with S → bB | b:

S → AB | aA | a | bB | b | ε; A → aA | a; B → bB | b. No unit productions remain.

### 2.3 Eliminating useless symbols

A symbol X is **useful** if S ⇒* αXβ ⇒* w for some terminal string w. Two tests, in this order: (1) keep only **generating** (productive) variables (those deriving some terminal string); (2) from what remains keep only symbols **reachable** from S.

**Worked example.** S → AB | a; A → aA | a; B → bB; C → c.

1. Generating: A (A → a), C (C → c), S (S → a). B → bB never terminates: **B not generating**. Delete B and every production containing it: S → a; A → aA | a; C → c.
2. Reachable from S: only S. A and C are not reachable; delete.

Result: **S → a**. (If you reverse the order — reachability first — you would keep A wrongly, which is why the order matters.)

### 2.4 Chomsky normal form (CNF)

Every production is **A → BC** (two variables) or **A → a** (one terminal) (plus possibly S → ε). Procedure: (1) remove ε, unit and useless rules; (2) for each terminal a in a right side of length ≥ 2, introduce C_a → a and replace; (3) break right sides longer than 2: A → B1B2…Bk becomes A → B1X1, X1 → B2X2, …

**Worked example: palindromes of length ≥ 1.** S → aSa | bSb | a | b | ε.

1. Drop ε (S still derives all nonempty palindromes): S → aSa | bSb | aa | bb | a | b. (The two new rules come from deleting the nullable S in the middle.)
2. Terminals inside long rules: P → a, Q → b. S → PSP | QSQ | PP | QQ | a | b.
3. Break long rules: S → PX | QY | PP | QQ | a | b; X → SP; Y → SQ.

**Final CNF:** S → PX | QY | PP | QQ | a | b; X → SP; Y → SQ; P → a; Q → b. (CYK on this grammar accepts exactly the palindromes of length 1…8 over {a,b}, checked by brute force.)

**Derivation length.** In CNF, deriving a string of length n ≥ 1 takes exactly **n − 1** steps of type A → BC (a binary tree with n leaves has n − 1 internal branching nodes) plus **n** steps of type A → a, total **2n − 1**. The parse tree is a binary tree. Example: a^3b^3 ∈ {a^n b^n}: 2·6 − 1 = **11** steps. Number of internal nodes with two children = n − 1.

### 2.5 Greibach normal form (GNF)

Every production is **A → aα** with a a terminal and α a (possibly empty) string of variables. Every CFL without ε has a GNF grammar. Each derivation step produces exactly one terminal, so a string of length n takes **exactly n steps**. Left recursion is impossible in GNF, and it translates directly into a PDA that makes no ε-moves. Example: S → aSb | ab becomes S → aSB | aB; B → b.

| Normal form | Production shape | Derivation steps for \|w\| = n |
| --- | --- | --- |
| CNF | A → BC \| a | 2n − 1 |
| GNF | A → aα | n |

## 3. Pushdown automata

**Intuition.** A DFA plus a stack of unbounded depth. The stack can remember one unbounded count or one reversible sequence (the most recent symbol is the one visible). That is exactly the memory needed for nesting.

**Definition.** NPDA M = (Q, Σ, Γ, δ, q0, Z0, F): states, input alphabet, stack alphabet, start state, start stack symbol, final states, and a transition function
δ: Q × (Σ ∪ {ε}) × Γ → finite subsets of Q × Γ*.
A move (q, a, X) → (p, γ) reads a, pops X, pushes γ (leftmost symbol of γ becomes the top). The ε-moves read no input. An *instantaneous description* is (state, remaining input, stack).

**Acceptance.** *By final state:* w accepted if (q0, w, Z0) ⊢* (f, ε, any stack) with f ∈ F. *By empty stack:* (q0, w, Z0) ⊢* (q, ε, ε) for any q. For NPDA both define exactly the CFLs (convert one to the other by adding a new bottom marker).

**DPDA.** For every (q, a, X) at most one move among {(q, a, X), (q, ε, X)}: no choice at all. Equivalently: whenever an ε-move exists for (q, X), no input-reading move exists for (q, X). DPDAs accept the **deterministic CFLs (DCFLs)**, and **DPDA with final-state acceptance ⊋ DPDA with empty-stack acceptance**.

### 3.1 Worked PDA: a^n b^n

Final-state version, stack alphabet {Z, A}, start q0, final q2:

| Move | Meaning |
| --- | --- |
| δ(q0, a, Z) = (q0, AZ) | first a: push A |
| δ(q0, a, A) = (q0, AA) | more a's: push A |
| δ(q0, b, A) = (q1, ε) | first b: pop A |
| δ(q1, b, A) = (q1, ε) | more b's: pop A |
| δ(q1, ε, Z) = (q2, Z) | stack back to bottom: accept |
| δ(q0, ε, Z) = (q2, Z) | accept ε (n = 0) |

Trace of aabb: (q0, aabb, Z) ⊢ (q0, abb, AZ) ⊢ (q0, bb, AAZ) ⊢ (q1, b, AZ) ⊢ (q1, ε, Z) ⊢ (q2, ε, Z) accept. Trace of aab: after a,a,b the configuration is (q1, ε, AZ); no ε-move applies when top is A, so it stops in a non-final state: rejected. Trace of abb: (q1, b, Z) has no move for b with Z: stuck, rejected. This machine is deterministic. (The empty-stack variant replaces the last moves by δ(q1, ε, Z) = (q1, ε) and δ(q0, ε, Z) = (q1, ε). Both versions were simulated against all strings up to length 8.)

### 3.2 Worked PDA: ww^R (needs nondeterminism)

Stack alphabet {Z, A, B}. In q0, push each symbol read; at any point **guess** that the middle was reached (ε-move to q1); in q1 pop on match; empty the stack on Z.

- δ(q0, a, X) = (q0, AX), δ(q0, b, X) = (q0, BX) for X ∈ {Z, A, B}
- δ(q0, ε, X) = (q1, X) (the guess)
- δ(q1, a, A) = (q1, ε), δ(q1, b, B) = (q1, ε)
- δ(q1, ε, Z) = (q1, ε) (accept by empty stack)

Input abba: push A, B; guess; read b: pop B; read a: pop A; Z removed: accepted. Input aaaa: the guess point can be after 0, 1, 2, 3, 4 symbols; only the guess after 2 works, which an NPDA is allowed to find. **A DPDA cannot decide where the middle is**, which is the intuition for ww^R ∉ DCFL. By contrast L = {w c w^R} has a visible middle marker c, so a DPDA handles it (push until c, then pop). All strings up to length 10 checked against a simulator.

### 3.3 CFG ⇄ PDA (idea)

- **CFG → PDA.** Keep the sentential form on the stack. Push S. Repeat: if the top is a variable A, nondeterministically replace it with the right side α of some A → α; if the top is a terminal equal to the next input symbol, pop it and consume. Accept on empty stack with input consumed. This simulates a leftmost derivation. Only one state is needed.
- **PDA → CFG.** Variables [p X q] meaning "starting in state p with X on top, the PDA can pop X and end in state q". Productions mirror the moves. The number of variables is O(|Q|²·|Γ|).
- So CFL ⇔ NPDA. The *single-state* PDA already has full CFL power with empty-stack acceptance.

### 3.4 Deterministic versus non-deterministic

| | Regular | DCFL | CFL |
| --- | --- | --- | --- |
| Machine | DFA ≡ NFA | DPDA | NPDA (more powerful than DPDA) |
| a^n b^n | no | yes | yes |
| w c w^R | no | yes | yes |
| ww^R | no | **no** | yes |
| Palindromes | no | **no** | yes |
| a^i b^j c^k, i = j or j = k | no | **no** | yes |
| a^i b^j c^k, i = j | no | yes | yes |
| Complement of {ww^R} | no | no | yes |

**Rule of thumb for CFL vs DCFL:** if the machine must *guess* the middle, a switching point, or which of two conditions to check ("i = j or j = k"), it is non-deterministic. If the language is one condition checked while reading (a^n b^n, a^n b^m with n < m, #a = #b), a DPDA suffices.

## 4. CYK algorithm (brief)

Decides w ∈ L(G) for G in CNF in **O(n³·|G|)** time. T[i, j] = set of variables deriving w[i..j]. T[i, i] = {A : A → w_i}. For longer spans, A ∈ T[i, j] if A → BC with B ∈ T[i, k], C ∈ T[k+1, j] for some i ≤ k < j. Accept iff S ∈ T[1, n].

**Worked example.** CNF grammar S → AX | AB, X → SB, A → a, B → b, and w = aaabbb (positions 1..6, a a a b b b).

| Span length | Entries (start position: set) |
| --- | --- |
| 1 | 1:{A} 2:{A} 3:{A} 4:{B} 5:{B} 6:{B} |
| 2 | only **3-4: {S}** (A at 3, B at 4); every other span is empty |
| 3 | only **3-5: {X}** (S at 3-4, B at 5); every other span is empty |
| 4 | only **2-5: {S}** (A at 2, X at 3-5); every other span is empty |
| 5 | only **2-6: {X}** (S at 2-5, B at 6); 1-5 is empty |
| 6 | **1-6: {S}** (A at 1, X at 2-6) |

S ∈ T[1,6], so aaabbb ∈ L. (Table computed by a program as well: the non-empty cells are exactly these.)

## 5. Closure properties

| Operation | Regular | DCFL | CFL |
| --- | --- | --- | --- |
| Union | yes | **no** | yes |
| Intersection | yes | **no** | **no** |
| Complement | yes | **yes** | **no** |
| Concatenation | yes | **no** | yes |
| Kleene star | yes | **no** | yes |
| Reversal | yes | **no** | yes |
| Difference | yes | no | no |
| Intersection with a regular language | yes | **yes** | **yes** |
| Homomorphism | yes | no | yes |
| Inverse homomorphism | yes | yes | yes |
| L1 ∪ L2 with L2 regular | yes | **yes** | yes |

**Why CFLs are not closed under intersection.** L1 = {a^n b^n c^m} (CFL: check a's against b's) and L2 = {a^m b^n c^n} (CFL: check b's against c's). L1 ∩ L2 = {a^n b^n c^n}, which is not a CFL ([Pumping lemma](pumping-lemma.md)). Since L1 ∩ L2 = complement(complement(L1) ∪ complement(L2)), and CFLs are closed under union, they cannot be closed under complement either.

**Why DCFLs are closed under complement but not union.** Complement: complete the DPDA (add a dead state, remove ε-loops) and swap final/non-final. Union fails: {a^i b^j c^k : i = j} ∪ {a^i b^j c^k : j = k} is a union of two DCFLs that is not a DCFL (it is the inherently ambiguous language above). Similarly intersection with an arbitrary DCFL fails (a^n b^n c^m ∩ a^m b^n c^n).

**Useful derived facts.**
- CFL ∩ regular = CFL (product of PDA and DFA). This is used to prove non-context-freeness: if L were CFL then L ∩ a*b*c* would be CFL.
- A subset of a CFL need not be a CFL. A union of finitely many CFLs is CFL; so is every finite language.
- The complement of a CFL need not be a CFL, but the complement of {ww} and of {a^n b^n c^n} **are** CFLs. That is why you cannot deduce "L is not CFL" from "complement is CFL".
- L and its complement both CFL does not imply regular (a^n b^n is a CFL with a CFL complement).

## 6. Decision properties

| Question | Regular | DCFL | CFL |
| --- | --- | --- | --- |
| Membership w ∈ L | D | D | D (CYK, O(n³)) |
| Emptiness | D | D | D (is S generating?) |
| Finiteness | D | D | D (cycle in the CNF dependency graph of useful variables) |
| Equivalence L1 = L2 | D | **D** (Sénizergues) | **U** |
| Universality L = Σ* | D | D | **U** |
| Inclusion L1 ⊆ L2 | D | U | U |
| Ambiguity of grammar | n/a | n/a | **U** |
| Disjointness L1 ∩ L2 = ∅ | D | U | U |
| "Is L(G) regular?" | trivial | D | U |
| "Is L(G) a DCFL?" | | | U |

D = decidable, U = undecidable. For GATE, remember: **membership, emptiness, finiteness are decidable for CFLs; equivalence, universality, ambiguity, disjointness, regularity-testing are not.** Equivalence of DPDAs is decidable but beyond GATE.

## 7. Classifying languages (regular / DCFL / CFL / not CFL)

| Language | Class | Reason |
| --- | --- | --- |
| a^n b^n | DCFL, not regular | single stack count |
| a^n b^m c^n | DCFL | push a's, ignore the b's, pop a's against c's |
| a^n b^n c^n | not CFL | two comparisons |
| a^n b^n c^m | DCFL | one comparison |
| a^n b^m c^n d^m | not CFL | crossing dependencies |
| a^n b^m c^m d^n | DCFL (nested) | nesting |
| ww | not CFL | copy needs queue-like access |
| w w^R | CFL, not DCFL | middle must be guessed |
| w c w | not CFL | copy |
| complement of {ww} | CFL | some position differs |
| {a^i b^j c^k : i ≠ j} | DCFL | compare and branch |
| a^i b^j c^k with i < j < k | not CFL | two inequalities need two counters |
| a^n for n prime, n^2, 2^n | not CFL | pumping; unary CFL ⇒ regular |
| a^n b^n, n ≤ 100 | regular | finite |
| equal a's and b's | DCFL | counter |
| strings with #a = 2·#b | DCFL | push 2 per b |

Key fact: **every CFL over a unary alphabet is regular**, so any non-regular unary language (a^(n²), a^(2^n), a^p) is not a CFL.

## GATE traps

- **Complement of a CFL is not a CFL in general**, but complement of a DCFL is a DCFL. "Complement of CFL" questions are typically traps for the DCFL case.
- Intersection of a CFL with a regular language is CFL; intersection of **two** CFLs is not.
- DPDA vs NPDA: do not assume palindromes are DCFL. Nondeterministic guess of the midpoint is essential.
- Ambiguous grammar does not mean ambiguous language; showing two parse trees proves the grammar ambiguous only.
- Do the simplification steps in order (ε, unit, useless); otherwise garbage rules survive.
- CNF derivation length is 2n − 1 only for n ≥ 1 and for ε-free CNF grammars. A CNF parse tree with n leaves has n − 1 internal binary nodes.
- A PDA accepting by empty stack but defined to run on an empty stack cannot move; ensure the bottom marker Z0 is present.
- {a^n b^n c^n} is not CFL but its complement is. Hence "L is not CFL ⇒ complement is not CFL" is false.
- Equal-count languages with a single pair of symbols are DCFL; with three symbols and two equalities they are not CFL.

## Practice

**Q1 (MCQ).** Which language is generated by S → aSb | ε?
(A) {a^n b^n : n ≥ 1} (B) {a^n b^n : n ≥ 0} (C) {a^n b^m} (D) {(ab)^n}

<details><summary>Answer</summary>

**Answer:** (B)  
**Solution:** Each use of S → aSb adds one a on the left and one b on the right; S → ε stops. After n uses plus the ε-rule we get a^n b^n for n ≥ 0 (including ε).

</details>

**Q2 (NAT).** A grammar in Chomsky normal form generates a string of length 7. How many derivation steps (rule applications) does the derivation have?

<details><summary>Answer</summary>

**Answer:** 13  
**Solution:** n − 1 = 6 binary rules A → BC and n = 7 terminal rules A → a: 6 + 7 = 13 = 2·7 − 1.

</details>

**Q3 (MSQ).** Which of the following are context-free? (A) {a^n b^m c^n : n, m ≥ 0} (B) {a^n b^n c^n : n ≥ 0} (C) {ww^R : w ∈ {a,b}*} (D) {a^n b^m c^m d^n : n, m ≥ 1}

<details><summary>Answer</summary>

**Answer:** A, C, D  
**Solution:** (A) push a's, ignore b's, pop for c's. (C) palindromes of even length: guess the middle. (D) nested: push a, push b, pop b against c, pop a against d. (B) needs two simultaneous comparisons, not CFL (pumping lemma).

</details>

**Q4 (MCQ).** Which statement is true?
(A) Every CFL is accepted by a DPDA. (B) The complement of every CFL is a CFL. (C) The intersection of a CFL and a regular language is a CFL. (D) The union of two DCFLs is a DCFL.

<details><summary>Answer</summary>

**Answer:** (C)  
**Solution:** (A) false: ww^R. (B) false: CFLs are not closed under intersection (a^n b^n c^m ∩ a^m b^n c^n), and since they are closed under union, they cannot be closed under complement. (D) false: {a^i b^j c^k : i=j} ∪ {a^i b^j c^k : j=k} is a union of two DCFLs that is not a DCFL. (C) holds by the product of the PDA with the DFA.

</details>

**Q5 (NAT).** The grammar S → SS | a is used. How many different parse trees does the string aaaa have?

<details><summary>Answer</summary>

**Answer:** 5  
**Solution:** Parse trees correspond to full binary bracketings of 4 leaves: Catalan C(3) = 5. Check by recurrence t(1)=1, t(2)=1, t(3)=t(1)t(2)+t(2)t(1)=2, t(4)=t(1)t(3)+t(2)t(2)+t(3)t(1)=2+1+2=5.

</details>

**Q6 (MCQ).** Simplify S → AB | a; A → aA | a; B → bB; C → c. The resulting grammar generates
(A) {a} (B) a+b* (C) a*b* (D) the empty language

<details><summary>Answer</summary>

**Answer:** (A)  
**Solution:** B never derives a terminal string (B → bB only), so every production using B is dropped. S → a remains and everything else is unreachable. L = {a}. (Enumeration of the original grammar gives only "a".)

</details>

**Q7 (NAT).** Using the CNF grammar S → AX | AB, X → SB, A → a, B → b, run CYK on aabb. How many table cells (spans) contain S?

<details><summary>Answer</summary>

**Answer:** 2  
**Solution:** Spans of aabb (positions 1-4): S derives "ab" at span 2-3 (A·B) and "aabb" at span 1-4 (A at 1, X at 2-4, where X = S·B = "ab"+"b"). No other span is S. So S appears in two cells, including the top cell, so aabb is accepted.

</details>

**Q8 (MCQ).** A PDA recognises L = {w ∈ {a,b}* : w = w^R} (palindromes). The minimum power of machine needed is
(A) DFA (B) DPDA with final-state acceptance (C) NPDA (D) Turing machine only

<details><summary>Answer</summary>

**Answer:** (C)  
**Solution:** Palindromes are context-free but not deterministic context-free: the machine must guess the middle (including odd-length palindromes, where the middle symbol is arbitrary). DFA cannot store the first half.

</details>
