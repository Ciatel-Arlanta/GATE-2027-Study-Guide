# Calculus — revision sheet

| Rule | Formula |
|---|---|
| Power rule | $(x^n)'=nx^{n-1}$ |
| Product | $(fg)'=f'g+fg'$ |
| Quotient | $(f/g)'=(f'g-fg')/g^2$ |
| Chain | $(f(g(x)))'=f'(g(x))g'(x)$ |
| Taylor at a | $f(a+h)=\sum f^{(k)}(a)h^k/k!+R$ |
| MVT | $f'(c)=[f(b)-f(a)]/(b-a)$ for some $c\in(a,b)$ |
| Definite integral | $\int_a^b f=F(b)-F(a)$ |
| Integration by parts | $\int u\,dv=uv-\int v\,du$ |

Critical points: solve $f'=0$ and include points where derivative is undefined. On a closed interval, compare all critical points and endpoints. $f''>0$ local min; $f''<0$ local max (when $f'=0$). Convex functions have nondecreasing derivative.
