# Computer Networks — revision sheet

| Concept | Recall |
|---|---|
| Transmission delay | packet bits / link bit rate |
| Propagation delay | distance / propagation speed |
| Store-and-forward | each router receives full packet before forwarding |
| CRC | polynomial remainder; detects burst errors up to generator properties |
| IPv4 | 32 bits; /p leaves 32−p host bits |
| Fragment offset | units of 8 bytes |
| Longest-prefix match | most specific matching CIDR route |
| DV | neighbour distance exchange; Bellman–Ford style |
| Link state | flood topology; local Dijkstra |
| TCP ACK | next byte expected; cumulative |
| TCP window | min(rwnd,cwnd) approximately |
| DNS | A=IPv4, AAAA=IPv6, CNAME=alias, MX=mail exchanger |
| HTTP codes | 2xx success, 3xx redirect, 4xx client, 5xx server |

Total nodal delay may include processing, queueing, transmission, and propagation. Keep bits, bytes, seconds, and rates in compatible units.
