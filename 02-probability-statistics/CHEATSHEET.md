# Probability & Statistics — revision sheet

| Item | Formula / fact |
|---|---|
| Complement | $P(A^c)=1-P(A)$ |
| Addition | $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ |
| Conditional | $P(A\mid B)=P(A\cap B)/P(B)$ |
| Bayes | $P(A_i\mid B)=P(B\mid A_i)P(A_i)/\sum_jP(B\mid A_j)P(A_j)$ |
| Expectation | $E[g(X)]=\sum g(x)p(x)$ or $\int g(x)f(x)dx$ |
| Variance | $E[X^2]-E[X]^2$; $Var(aX+b)=a^2Var(X)$ |
| Binomial | $P(X=k)=\binom nkp^k(1-p)^{n-k}$; mean np; variance np(1-p) |
| Poisson | $P(X=k)=e^{-\lambda}\lambda^k/k!$; mean=variance=$\lambda$ |
| Uniform [a,b] | mean $(a+b)/2$, variance $(b-a)^2/12$ |
| Exponential rate $\lambda$ | survival $e^{-\lambda t}$; mean $1/\lambda$ |
| Normal standardise | $Z=(X-\mu)/\sigma$ |
| Standard error | $\sigma/\sqrt n$ |
| z interval (known sigma) | $\bar x\pm z_{\alpha/2}\sigma/\sqrt n$ |

Independence: $P(A\cap B)=P(A)P(B)$; zero covariance does not imply independence in general. Continuous RV: probability is area under PDF; single points have probability zero.
