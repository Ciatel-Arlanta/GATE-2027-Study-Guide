# Memory management

> **Paper:** CS · **Priority:** P0 · **Plan topics:** address binding, logical/physical address, contiguous allocation, paging, segmentation, fragmentation
> **Prerequisites:** [Computer organisation: memory hierarchy](../10-computer-organization/memory-hierarchy-and-cache.md) · **Leads to:** [Virtual memory](virtual-memory.md)

## Quick glance
- Logical/virtual address is generated by CPU; physical address names a location in RAM.
- Paging maps fixed-size pages to frames; page offset is unchanged by translation.
- For page size $2^k$, low k address bits are offset; remaining bits are page number.
- Internal fragmentation is unused space inside allocated block; external fragmentation is scattered free holes.
- Segmentation uses variable-sized logical units and can suffer external fragmentation.

## 1. Address translation and paging
With 16-bit logical addresses and 1 KiB pages ($2^{10}$), offset uses 10 bits and page number uses 6. Logical address `0x1234` has page number 4 and offset `0x234` (divide by 0x400). If page 4 maps to frame 9, physical address is frame base `0x2400` + `0x234` = `0x2634`.

Page table maps each process page to a physical frame. Protection bits and valid/present bits control access. A TLB caches recent translations; its performance is detailed in [virtual memory](virtual-memory.md).

## 2. Allocation and fragmentation
Fixed partitions and paging can waste space internally. Variable-sized contiguous regions can leave external holes; compaction may combine them if relocation is supported. First-fit scans from start; best-fit chooses smallest adequate hole; worst-fit chooses largest.

## 3. Segmentation
A logical address is (segment, offset). Segment table stores base and limit; valid iff offset < limit, then physical=base+offset. Segmentation matches program structure but variable sizes complicate allocation.

## GATE traps
- Page number and offset bit counts depend on address width and page size.
- Paging eliminates external fragmentation, not internal fragmentation.
- Offset is unchanged during paging translation.
- Segmentation's bound is an offset limit, not physical memory size.
