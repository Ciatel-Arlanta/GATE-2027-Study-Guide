# General Aptitude — one-page revision

## Read and reason
- Subject–verb agreement follows the head noun; **each/every/neither** is normally singular.
- “If P then Q” has contrapositive “if not Q then not P”; converse is not guaranteed.
- Sequence paragraphs: opener → reference words → cause/effect → conclusion.
- Eliminate choices that introduce facts not stated in the passage.

## Calculate
| Quantity | Rule |
|---|---|
| Percentage change | $(new-old)/old\times100\%$ |
| Successive percentage changes | Multiply the factors, e.g. +p%, −q%: $(1+p/100)(1-q/100)$ |
| Weighted mean | $\sum f_ix_i/\sum f_i$ |
| Speed | distance/time; equal-distance average speed is harmonic |
| Work | Add rates (jobs/time), then invert total rate |
| Choose r from n | $\binom nr=n!/[r!(n-r)!]$ |
| Arrange r from n | $P(n,r)=n!/(n-r)!$ |
| Similar lengths / areas / volumes | $k, k^2, k^3$ |

## Spatial
- 90° CCW: $(x,y)\to(-y,x)$; vertical reflection: $(x,y)\to(-x,y)$.
- Reverse transformations in reverse order; use asymmetric marks to track orientation.
- Undo folds one at a time; each fold mirrors every cut/hole.
