# Brief: 13-operating-systems (CS; ~9-10 marks)

Plan topics: System calls; Processes; Threads; Inter-process communication; Concurrency; Synchronization; Deadlocks; CPU scheduling; I/O scheduling; Memory management; Virtual memory; File systems.

Files: README.md, processes-threads-syscalls.md, cpu-scheduling.md, synchronization.md, deadlocks.md, memory-management.md, virtual-memory.md, file-systems-and-disk-scheduling.md, CHEATSHEET.md, CHECKPOINT.md.

Verify scheduling Gantt charts, page-replacement fault counts, paging arithmetic and disk-scheduling head movement with small Python simulations. Run fork() examples mentally with process trees (and with gcc if available on a POSIX shell; otherwise trace carefully).

Must cover:
- System calls and kernel: user vs kernel mode, mode switch vs context switch, system-call mechanism (trap), categories, interrupts vs traps vs exceptions.
- Processes: PCB, process states and the transition diagram (mermaid), schedulers (long/short/medium term), context switching; fork() semantics and counting processes/printed lines for fork-in-loop and fork with && / || (GATE favourite, multiple worked examples with process trees), exec, wait, zombies and orphans.
- Threads: user vs kernel threads, multithreading models (many-to-one, one-to-one, many-to-many), what threads share vs keep private.
- IPC: shared memory vs message passing, pipes, producer-consumer.
- CPU scheduling: criteria and definitions (arrival, burst, completion, turnaround, waiting, response time; throughput; CPU utilisation with context-switch overhead); FCFS (convoy effect), SJF, SRTF, priority (preemptive/non-preemptive, starvation and aging), Round Robin (effect of quantum, context-switch counting), HRRN, multilevel queue and feedback queue; full Gantt-chart worked examples with average waiting/turnaround times; optimality of SJF/SRTF; I/O-bound + CPU-bound mixed bursts.
- Synchronization: race conditions, the critical-section problem and its three requirements (mutual exclusion, progress, bounded waiting); analysing proposed two-process solutions (strict alternation, flag-based, Peterson) for which requirements fail — a GATE favourite; hardware support (TestAndSet, Swap/CompareAndSwap, disabling interrupts); spinlocks and busy waiting; semaphores (counting and binary; wait/signal definitions; computing final semaphore value after sequences of P/V; ordering constraints with semaphores); mutexes; monitors and condition variables; classic problems — bounded buffer, readers-writers (first/second variants and starvation), dining philosophers (deadlock and fixes), sleeping barber (brief); counting possible final values of a shared variable under concurrent execution (interleaving analysis, worked examples).
- Deadlocks: four Coffman conditions; resource-allocation graphs (cycle vs deadlock with single vs multiple instances); prevention (breaking each condition), avoidance (safe state, Banker's algorithm fully worked with Need matrix and safety sequence, resource-request algorithm), detection and recovery; minimum resources to guarantee no deadlock: R >= n(m - 1) + 1 type formulas (worked); starvation vs deadlock vs livelock.
- Memory management: logical vs physical addresses, MMU, base/limit; contiguous allocation (fixed/variable partitions, first/best/worst/next fit traced), internal vs external fragmentation, compaction; paging (page/frame arithmetic, page-table size, PTE contents), TLB and effective memory access time (EMAT with TLB hit ratio, with/without page faults), multilevel paging (bits per level, page-table sizes, memory accesses), inverted page tables, hashed page tables; segmentation and segmentation with paging.
- Virtual memory: demand paging, page-fault handling steps, effective access time with page-fault rate; page replacement — FIFO, Optimal, LRU, LRU approximations (clock/second chance), counting faults for reference strings (multiple worked examples), Belady's anomaly (FIFO yes, stack algorithms no); frame allocation, thrashing, working-set model, page-fault frequency; copy-on-write; page size trade-offs.
- File systems: file concepts, directory structures, allocation methods (contiguous, linked, FAT, indexed, multilevel indexed / UNIX inode with direct, single, double, triple indirect blocks — maximum file size calculations), free-space management (bit vector, linked list), disk structure (platters, tracks, sectors, cylinders), disk access time = seek + rotational latency + transfer (worked numerics).
- I/O (disk) scheduling: FCFS, SSTF, SCAN, C-SCAN, LOOK, C-LOOK with total head-movement calculations on one request queue, starvation properties, comparison table.
