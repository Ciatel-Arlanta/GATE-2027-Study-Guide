# Brief: 16-machine-learning + 17-artificial-intelligence (DA paper; ML ~15-20 marks, AI ~8-12 marks)

Verify every numeric example (regression coefficients, k-NN votes, naive Bayes posteriors, entropy/information gain, k-means iterations, linkage merges, PCA components, A* expansions, minimax values, alpha-beta prunes, Bayesian-network probabilities) with small Python/numpy scripts.

## 1) 16-machine-learning/
Plan topics: Regression vs classification problems; Simple linear regression; Multiple linear regression; Ridge regression; Logistic regression; k-nearest neighbours; Naive Bayes classifier; Linear discriminant analysis; Support vector machines; Decision trees; Bias-variance trade-off; Leave-one-out cross-validation; k-fold cross-validation; Multi-layer perceptron; Feed-forward neural networks; Clustering; k-means; k-medoids; Hierarchical clustering: top-down; Hierarchical clustering: bottom-up; Single-linkage clustering; Multiple-linkage clustering; Dimensionality reduction; Principal component analysis.
Files: README.md, ml-foundations.md, linear-and-logistic-regression.md, classification-methods.md, neural-networks.md, clustering.md, dimensionality-reduction-pca.md, CHEATSHEET.md, CHECKPOINT.md.
Must cover:
- Foundations: supervised vs unsupervised; regression vs classification; training/validation/test; loss functions (squared, absolute, 0-1, cross-entropy, hinge); empirical risk; overfitting/underfitting; bias-variance decomposition (expected error = bias^2 + variance + noise) and how model complexity, regularisation, k in k-NN, tree depth and training-set size move each term; cross-validation — k-fold (number of model fits), LOOCV (n fits; nearly unbiased, high variance), stratified; evaluation metrics (confusion matrix, accuracy, precision, recall, F1, specificity; worked); MLE as the principle behind several models.
- Linear regression: simple LR closed form (beta1 = Sxy/Sxx, beta0 = ybar - beta1 xbar) worked on a small dataset; residuals, R^2; multiple LR via normal equations beta = (X^T X)^-1 X^T y (link 03-linear-algebra projections), geometric view as projection; assumptions; gradient descent update; ridge regression (objective, closed form (X^T X + lambda I)^-1 X^T y, shrinkage effect, always invertible for lambda > 0, effect on bias/variance; contrast with lasso briefly).
- Logistic regression: sigmoid, log-odds linear in x, decision boundary is linear, cross-entropy loss (why not squared), gradient (y_hat - y) x, worked prediction; multiclass softmax brief.
- k-NN: distance metrics (Euclidean, Manhattan, Minkowski, cosine), effect of k (k = 1 training error is 0), feature scaling, curse of dimensionality, worked classification with ties; complexity.
- Naive Bayes: conditional-independence assumption, posterior proportional to prior x product of likelihoods, worked categorical example (table) with Laplace smoothing, Gaussian NB, why it is a linear classifier in some cases.
- LDA: Gaussian class-conditionals with shared covariance -> linear boundary; Fisher's criterion (maximise between-class over within-class scatter), 1-D/2-D worked projection; LDA vs QDA vs logistic regression.
- SVM: margin, hard vs soft margin (C), support vectors, primal objective, hinge loss, kernel trick (polynomial, RBF; kernel computed as inner product), worked example finding the max-margin line for small separable data, number of support vectors questions.
- Decision trees: entropy, Gini, information gain, gain ratio (brief); worked ID3 split selection on a small table; overfitting and pruning; trees for regression (variance reduction) brief; ensembles (bagging/random forest/boosting) one paragraph each.
- Neural networks: perceptron (update rule, linear separability, XOR not separable), MLP/feed-forward architecture, activation functions (sigmoid, tanh, ReLU, softmax with derivatives), forward pass worked numerically, backpropagation with a tiny 2-layer example worked numerically, counting parameters (weights + biases) for a given architecture, universal approximation (statement), vanishing gradients (brief), a network with linear activations collapses to a linear model.
- Clustering: k-means (objective, Lloyd's algorithm iterations worked by hand on 1-D/2-D points, convergence to local optimum, initialisation sensitivity, choosing k / elbow), k-medoids (PAM, medoid must be a data point, robustness to outliers, worked), hierarchical clustering — agglomerative (bottom-up) with single, complete, average linkage (and centroid/Ward briefly) traced on a distance matrix with dendrogram; divisive (top-down) idea; single linkage = MST-based (link to 08-algorithms/minimum-spanning-trees.md), chaining effect; "multiple-linkage" in the syllabus = complete/average/other linkage criteria — say so explicitly.
- Dimensionality reduction and PCA: motivation, centring, covariance matrix, eigen-decomposition, principal components = eigenvectors ordered by eigenvalue, variance explained ratio, projecting data, PCA via SVD of centred data, worked 2-D example with numbers, choosing number of components, PCA is unsupervised (vs LDA supervised).

## 2) 17-artificial-intelligence/
Plan topics: Uninformed search; Informed search; Adversarial search; Propositional logic; Predicate logic; Conditional independence; Representation of conditional independence; Exact inference via variable elimination; Approximate inference via sampling.
Files: README.md, search.md, logic-and-inference.md, probabilistic-reasoning.md, CHEATSHEET.md, CHECKPOINT.md.
Must cover:
- Search: problem formulation (state space, actions, goal test, path cost); tree vs graph search; uninformed: BFS, uniform-cost, DFS, depth-limited, iterative deepening, bidirectional — table of completeness, optimality, time and space in terms of b, d, m; node-expansion order traces on a given graph (GATE style); informed: greedy best-first, A* (f = g + h), admissible and consistent heuristics, A* optimality conditions, worked A* trace with open/closed lists, effect of h = 0 (uniform-cost) and of inadmissible h; heuristic dominance; IDA* briefly; local search (hill climbing, simulated annealing) briefly; adversarial: game trees, minimax worked, alpha-beta pruning worked (which nodes get pruned; best-case O(b^(m/2))), move ordering, expectiminimax briefly.
- Logic: propositional logic for KR (link the full treatment in 01-discrete-mathematics/propositional-logic.md rather than repeating it), entailment vs satisfiability vs validity, model checking, inference rules, CNF conversion, resolution refutation worked, Horn clauses, forward and backward chaining; predicate (first-order) logic: syntax, quantifiers, translation from English (link 01-discrete-mathematics/first-order-logic.md), unification (MGU worked), Skolemisation, resolution in FOL worked.
- Probabilistic reasoning: joint distributions, marginalisation, conditioning, independence and conditional independence (definitions and checks), Bayesian networks (DAG + CPTs, chain-rule factorisation, parameter counting vs full joint, d-separation with the three canonical structures — chain, fork, collider/explaining away — worked), Markov blanket; exact inference by enumeration and by variable elimination (worked numerically on a small network such as burglary-alarm; elimination order affects cost); approximate inference by sampling — prior/direct sampling, rejection sampling, likelihood weighting (worked weights), Gibbs sampling / MCMC (idea); naive Bayes as a special Bayesian network (link 16-machine-learning/classification-methods.md).
