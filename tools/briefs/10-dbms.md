Must cover:
- ER model: entities, attributes (simple/composite/multivalued/derived/key), relationships, cardinality ratios and participation (total/partial), weak entities and identifying relationships, specialisation/generalisation; ER -> relational mapping rules and minimum number of tables for given ER diagrams (a GATE favourite; worked examples for 1:1, 1:N, M:N with total/partial participation, multivalued attributes).
- Relational model: relation, tuple, attribute, domain, degree, cardinality; keys (super, candidate, primary, alternate, foreign); counting super keys (worked); NULL semantics.
- Relational algebra: select, project (duplicate elimination), rename, union/intersection/difference (union compatibility), Cartesian product, joins (theta, equi, natural, outer — left/right/full), division (with the standard expression and a worked "students who took all courses" example); min/max tuple counts for each operator (GATE favourite); query equivalences.
- Tuple relational calculus: syntax, safe expressions, translating between TRC, RA and SQL, universal quantification patterns; domain calculus briefly.
- SQL: DDL/DML, SELECT evaluation order (FROM -> WHERE -> GROUP BY -> HAVING -> SELECT -> ORDER BY), NULL three-valued logic and aggregates ignoring NULL (COUNT(*) vs COUNT(col)), GROUP BY/HAVING, nested and correlated subqueries, IN/EXISTS/ANY/ALL (with empty-set behaviour: `> ALL (empty)` is true), set operations with/without ALL, joins, views, duplicates (SQL is a multiset), output-tracing questions on given tables (several worked).
- Integrity constraints: domain, key, entity, referential integrity with ON DELETE CASCADE / SET NULL behaviour (trace cascading deletes — GATE favourite), CHECK, assertions, triggers (brief).
- Normalisation: anomalies; functional dependencies, Armstrong's axioms, attribute closure, finding all candidate keys (systematic method), FD-set equivalence and canonical/minimal cover; prime attributes; 1NF, 2NF, 3NF, BCNF (definitions and tests, highest normal form questions), 4NF and MVDs (brief); decomposition: lossless join (common-attribute superkey test; chase for 3+ relations) and dependency preservation; 3NF synthesis and BCNF decomposition algorithms worked fully; BCNF may lose dependency preservation.
- File organisation and indexing: records and blocks, blocking factor, heap/sequential/hashed files; primary, clustering, secondary indexes; dense vs sparse; multilevel indexes; block-access-count calculations (worked); B trees and B+ trees: order definitions (state convention, and how GATE defines it), node structure, computing order from block size / key size / pointer size (worked), minimum/maximum keys and nodes per level, height bounds, insertion with splits and deletion with merges (traced), why B+ trees for range queries.
- Transactions: ACID; states; schedules (serial, serialisable); conflict serialisability via precedence graph (worked), view serialisability (blind writes), testing recoverable, cascadeless (ACA), strict schedules — the hierarchy diagram; counting conflict-equivalent serial schedules.
- Concurrency control: lock-based protocols (shared/exclusive, 2PL basic/strict/rigorous/conservative and what each guarantees: serialisability, cascadelessness, deadlock-freedom), deadlock handling (wait-die, wound-wait), timestamp ordering (basic, Thomas write rule), multiple granularity (brief), MVCC (brief), recovery basics (log-based, undo/redo, checkpoints) as needed.
- Data warehousing and preprocessing (DA): OLTP vs OLAP; data types (nominal, ordinal, interval, ratio; discrete vs continuous); data transformation — normalisation (min-max, z-score, decimal scaling; worked numerics — distinguish from schema normalisation); discretisation (equal-width, equal-frequency binning, entropy-based briefly); sampling (SRS with/without replacement, stratified, cluster); compression/data reduction (dimensionality reduction link to PCA, numerosity reduction, lossless vs lossy); multidimensional model: data cube, facts and dimensions, star/snowflake/fact-constellation schemas; OLAP operations (roll-up, drill-down, slice, dice, pivot); concept hierarchies (schema vs set-grouping hierarchies); measures: distributive, algebraic, holistic (with examples like sum, avg, median); number of cuboids in a cube = product of (L_i + 1) for hierarchies (worked).
