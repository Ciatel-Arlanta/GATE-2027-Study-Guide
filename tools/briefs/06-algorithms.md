# Brief: 08-algorithms (CS+DA; CS ~8-10 marks; DA covers the "basic" subset: search, simple sorts, merge/quick sort, traversals, shortest path)

Plan topics: Asymptotic notation and growth rates; Worst-case time complexity; Worst-case space complexity; Linear search; Binary search; Selection sort; Bubble sort; Insertion sort; Merge sort; Quicksort; Hashing; Divide and conquer; Greedy algorithms; Dynamic programming; Graph representations (taught in 07-data-structures/graphs.md — link to it); Graph traversal: BFS; Graph traversal: DFS; Minimum spanning trees; Shortest paths.

Files: README.md, asymptotic-analysis.md, searching-and-sorting.md, hashing.md, divide-and-conquer.md, greedy-algorithms.md, dynamic-programming.md, graph-traversals.md, minimum-spanning-trees.md, shortest-paths.md, CHEATSHEET.md, CHECKPOINT.md.

Verify traces and DP tables by running small Python implementations.

Must cover:
- Asymptotics: O, Omega, Theta, o, omega definitions with constants; growth-rate ordering ladder (log* n, log log n, log n, sqrt n, n, n log n, n^2, 2^n, n!, n^n), comparing functions by taking logs, properties (transitivity, max rule), loop-analysis patterns (nested, logarithmic, harmonic, dependent loops) with worked counts; recurrences: substitution, recursion tree, Master theorem (all three cases plus the extended log-factor case), and cases where it does not apply (e.g. T(n) = 2T(sqrt n) + log n via change of variable); space complexity incl. recursion-stack depth.
- Searching/sorting: linear and binary search (iterative code, off-by-one traps, comparison counts); selection, bubble (with early exit), insertion (#swaps = #inversions); merge sort (merge cost, comparisons in the best and worst case for merging two lists); quicksort (Lomuto vs Hoare partition traces, worst case on sorted input, randomised expected O(n log n), recursion depth); heap sort; counting and radix sort; a master table (best/avg/worst, space, stable?, in-place?, adaptive?, number of swaps); lower bound Omega(n log n) for comparison sorting via decision trees; finding the k-th smallest (quickselect, median of medians brief); minimum comparisons for min+max (ceil(3n/2) - 2) and second-largest (n + ceil(log n) - 2).
- Hashing: hash functions (division, multiplication, mid-square, folding), collision resolution (chaining; open addressing with linear and quadratic probing and double hashing), primary/secondary clustering, load factor, expected probes for successful/unsuccessful search (uniform-hashing formulas), insertion-trace questions with a table, deletion with tombstones, universal hashing (brief).
- Divide and conquer: merge sort, quicksort, binary search, max-subarray, closest pair (brief), Strassen (7 multiplications, n^log2(7)), Karatsuba, power x^n in O(log n), counting inversions.
- Greedy: greedy-choice property and optimal substructure; activity selection; fractional knapsack; Huffman coding (build tree, compute average code length / total bits); job sequencing with deadlines; optimal merge pattern; why greedy fails for 0/1 knapsack and for coin change with arbitrary denominations (counterexample).
- DP: overlapping subproblems and optimal substructure, memoization vs tabulation; Fibonacci; 0/1 knapsack (full table); LCS (full table + reconstruction); edit distance; matrix-chain multiplication (full m-table, a GATE favourite); longest increasing subsequence; coin change (ways and minimum coins); subset sum; rod cutting; Floyd-Warshall and Bellman-Ford as DP; optimal BST (brief); complexity of each.
- Graph traversals: BFS (queue, levels, shortest path in unweighted graphs, BFS tree, O(V+E)), DFS (discovery/finish times, edge classification tree/back/forward/cross for directed and undirected graphs, parenthesis theorem), cycle detection, topological sort (DFS finish order and Kahn's algorithm; counting topological orders for small DAGs), connected components, strongly connected components (Kosaraju), articulation points and bridges (brief).
- MST: cut property and cycle property; Kruskal (with union-find, sort cost) and Prim (with binary heap; matrix vs list complexity) traced step by step; uniqueness of MST when weights are distinct; GATE-style properties (max-weight edge in a cycle not in MST, MST weight with modified weights, number of MSTs).
- Shortest paths: relaxation; Dijkstra (trace table, fails with negative edges — counterexample, complexity with array/binary heap/Fibonacci heap); Bellman-Ford (V-1 passes, negative-cycle detection, trace); Floyd-Warshall (matrix trace); DAG shortest path via topological order; BFS for unit weights; comparison table.
