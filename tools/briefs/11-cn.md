# Brief: 15-computer-networks (CS; ~8-10 marks)

Note: the GATE 2027 CS syllabus trimmed this subject to: principles of layering; basics of switching (circuit, packet, virtual circuit) and performance metrics; data link layer — error detection, medium access control, Ethernet; distance-vector and link-state routing; IPv4 — fragmentation, CIDR notation, NAT; TCP — flow control, congestion control, socket API; DNS and HTTP. Teach these in depth; mention in the README that ARP/DHCP/ICMP, UDP, SMTP/FTP and framing/bridging were dropped from the explicit 2027 list, and cover them briefly only where needed to understand the listed topics (e.g. the UDP vs TCP contrast; sliding-window protocols, which underpin TCP flow control and are classic GATE numericals).

Plan topics: Principles of layering; Circuit switching; Packet switching; Virtual circuit switching; Network performance metrics; Data-link layer; Error detection; Medium Access Control; Ethernet; Distance-vector routing; Link-state routing; IPv4; IPv4 fragmentation; CIDR notation; Network Address Translation; TCP flow control; TCP congestion control; Socket API; DNS; HTTP.

Files: README.md, layering-switching-performance.md, data-link-layer.md, routing.md, ipv4-addressing.md, transport-layer-tcp.md, application-layer.md, CHEATSHEET.md, CHECKPOINT.md.

Verify every numerical (delays, efficiencies, CRC remainders, subnet ranges, fragment offsets, window sizes) with Python.

Must cover:
- Layering: OSI vs TCP/IP stacks, encapsulation, which layer does what, PDUs per layer, which devices operate at which layer, protocol header overheads.
- Switching: circuit switching (setup, reserved bandwidth), packet switching (store-and-forward, datagram), virtual circuits (setup, per-VC state, label switching); delay comparison worked numerically (message vs packet switching over k hops, pipelining effect of smaller packets — GATE favourite).
- Performance metrics: bandwidth, throughput, transmission delay L/R, propagation delay d/v, queuing and processing delay, RTT, bandwidth-delay product, utilisation; units traps (KB = 1000 vs 1024, bits vs bytes).
- Data link: framing (briefly: byte/bit stuffing), error detection — parity (single, 2D), Internet checksum, CRC (polynomial division worked fully, which errors CRC detects), Hamming distance (detect d-1, correct floor((d-1)/2)), Hamming code (brief); flow control — stop-and-wait, Go-Back-N, Selective Repeat: efficiency formulas with a = Tp/Tt, window-size bounds with sequence-number bits (GBN <= 2^k - 1, SR <= 2^(k-1)), retransmission counting under losses (worked), piggybacking.
- MAC: channel partitioning vs random access vs taking turns; pure and slotted ALOHA (throughput S = G e^(-2G) and G e^(-G), maxima 18.4% and 36.8%), CSMA variants, CSMA/CD with minimum frame size = 2 x Tp x bandwidth (worked), binary exponential backoff, CSMA/CA (brief), token passing (brief).
- Ethernet: frame format, MAC addresses, minimum/maximum frame sizes, efficiency of Ethernet, switches vs hubs, collision vs broadcast domains, learning switches (brief).
- Routing: distance-vector (Bellman-Ford, table-update traces, count-to-infinity, split horizon, poison reverse), link-state (LSA flooding, Dijkstra at each router), comparison table; link with 08-algorithms/shortest-paths.md.
- IPv4: header fields (TTL, protocol, header length in 4-byte units, total length, identification, flags DF/MF, fragment offset in 8-byte units, checksum); fragmentation worked fully (number of fragments, offsets, MF bits, sizes, reassembly at destination, total overhead); classful addressing (brief); subnetting and supernetting; CIDR (prefix, block size, network/broadcast addresses, number of hosts, longest-prefix-match forwarding — worked routing-table lookups; route aggregation); private address ranges; NAT (translation table, port mapping, NAT and end-to-end connectivity); mention ARP/ICMP/DHCP in one line each.
- Transport: ports and multiplexing; UDP (header, when used) in brief; TCP header, three-way handshake and teardown (state diagram brief), sequence/ack numbers (byte-based; worked examples), wrap-around time of sequence numbers, window scaling, flow control with receiver window (rwnd), sliding-window throughput = window/RTT; congestion control — slow start, congestion avoidance (AIMD), ssthresh, fast retransmit/fast recovery, timeout vs triple-duplicate-ACK behaviour (Tahoe vs Reno), cwnd evolution traced RTT by RTT (GATE favourite), effective window = min(cwnd, rwnd); timeout estimation (EWMA RTT, Jacobson/Karn brief).
- Sockets: client/server call sequence (socket, bind, listen, accept, connect, send/recv, close) for TCP and UDP; which calls block; which are server-only (GATE asks this).
- DNS: hierarchy, root/TLD/authoritative servers, recursive vs iterative resolution (count messages), caching and TTL, record types (A, AAAA, NS, CNAME, MX), DNS uses UDP port 53 (TCP for large/zone transfers).
- HTTP: request/response format, methods, status codes, persistent vs non-persistent connections, pipelining; page-load time calculations with RTTs (e.g. base HTML + k objects under non-persistent, persistent, parallel connections — worked), cookies, caching/conditional GET, HTTP over TCP port 80, HTTPS 443.
